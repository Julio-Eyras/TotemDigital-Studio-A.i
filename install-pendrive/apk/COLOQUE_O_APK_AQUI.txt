Nesta pasta deve existir o APK release do Player-AD (já incluído no kit), com nome versionado:

  Player-AD-Vs{versionName}-build-{versionCode}.apk

Exemplo actual:
  Player-AD-Vs2.13-build-113.apk

Não usar mais o nome legado Player-AD-release.apk.

Gere/atualize a partir do projeto:

  cd Player-AD
  ./gradlew assembleRelease
  # Windows:
  .\scripts\prepare-install-pendrive.ps1 -Rebuild
  # Linux/macOS:
  bash scripts/prepare-install-pendrive.sh
