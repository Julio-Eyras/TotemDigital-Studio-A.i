# Visão de produto — Totem Digital V3x

**Data:** 2026-05-12

## Uma frase

O Totem Digital V3x permite que um negócio **publique conteúdo aprovado nas suas telas em minutos**, sem montar manualmente playlists nem campanhas.

## Fluxo principal

Cliente (anunciante) → escolhe **tela/totem** → escolhe **conteúdo** (existente ou enviado no fluxo) → **Publicar**. O sistema cria playlist, campanha e vínculos; o player atualiza.

## Princípios

1. **Primeira impressão comercial**: dashboard e atalhos falam a língua do negócio, não só a do operador técnico.
2. **Ativação simples**: código curto no player e vinculação no painel.
3. **Player suportado**: Linux + Chromium kiosk como base de piloto; Electron/branding como evolução documentada.
4. **Self-hosted primeiro**: SaaS gerenciado é fase posterior explícita no roadmap.

## O que fica fora do escopo imediato

Pilotos com clientes reais, material de marketing, SaaS cloud completo e módulos avançados (IA, marketplace) seguem o `docs/ROADMAP_TOTEM_DIGITAL_V3X.md` por fase.
