# Prévia Conceitual — Smart Signage (Explosão de Logo)

## Visão Geral
Este documento registra a prévia conceitual do vídeo de **20 segundos em loop** para o projeto **Smart Signage**, comparando duas abordagens cromáticas:

- 🔵 **Azul IBM (Corporativo)**
- 🔴 **Vermelho (Impacto)**

A prévia tem como objetivo validar **estilo, ritmo e impacto visual** antes do render 3D final no Blender.

---

## Conceito de Animação
- Logo central em fundo preto
- Formação inicial do símbolo **S**
- Explosão controlada em shards (fragmentos metálicos)
- Dispersão radial com partículas
- Reaglutinação suave para loop perfeito

---

## Comparativo Visual
### Azul IBM
- Sensação: tecnologia, estabilidade, corporativo
- Uso indicado: ambientes internos, branding contínuo, DOOH 24/7

### Vermelho
- Sensação: energia, impacto, atenção imediata
- Uso indicado: vitrines, campanhas curtas, chamadas promocionais

---

## Características Técnicas Planejadas
- Loop contínuo
- Sem áudio
- Pensado para WebOS e Android TV
- Pipeline: Blender → PNG frames → FFmpeg
