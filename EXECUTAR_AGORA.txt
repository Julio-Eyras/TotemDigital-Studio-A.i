PROBLEMA:
  Arquivos de mídia retornam 404 porque o Nginx não tem 
  permissão para ler os arquivos diretamente.

SOLUÇÃO RÁPIDA:
  Execute o comando abaixo (precisa de sudo):

  sudo python3 /home/smartchannel/SmartSignage-Pro/scripts/corrigir-nginx-assets.py
  sudo nginx -t && sudo systemctl reload nginx

OU use o script bash:

  sudo /home/smartchannel/SmartSignage-Pro/scripts/fix-nginx-assets-now.sh

  1. ✅ Backup automático da configuração do Nginx
  2. ✅ Substituição de 'alias' por 'proxy_pass' 
  3. ✅ Nginx passará a fazer proxy para o backend (porta 3000)
  4. ✅ Backend já está servindo os arquivos corretamente
