# Kit pendrive — SmartSignage-AD

Use esta pasta como base para instalacao do app Android SmartSignage-AD.

## Estrutura

- `apk/` - coloque o APK release (`app-release.apk`)
- `config/app-config.example.json` - modelo de configuracao
- `scripts/install-from-pc-adb.bat` - instalacao via ADB no Windows
- `scripts/install-from-pc-adb.sh` - instalacao via ADB no Linux/macOS

## Instalacao Windows

```cmd
scripts\install-from-pc-adb.bat
```

## Instalacao Linux/macOS

```bash
bash scripts/install-from-pc-adb.sh
```
